## 🎨 Design System

### Color Palette
- **Primary**: Purple Gradient (#667eea → #764ba2)
- **Success**: Green Gradient (#2ecc71 → #27ae60)
- **Danger**: Red Gradient (#e74c3c → #c0392b)
- **Warning**: Orange Gradient (#f39c12 → #d68910)
- **Info**: Blue Gradient (#3498db → #2980b9)

### Components
- Button (7 variants)
- Card (with header slot)
- Modal (reusable)
- Notification (auto-dismiss)
- SummaryCard (metrics)
- Table (sortable)

### Responsive Breakpoints
- Desktop: 1200px+
- Tablet: 768px - 1199px
- Mobile: < 768px
